# N0THING_in_order
Proyecto para app de material

Fase 1 (MVP)
1. Login/Registro básico
2. CRUD de productos
3. Vista de inventario con alertas de stock bajo
4. Dashboard simple con estadísticas

Fase 2:
5. Sistema de pedidos
6. Integración con Gmail
7. Calendario de eventos

Fase 3:
8. Bloc de notas
9. Reportes y exportación
10. Mejoras de UX

Paleta de colores:

- Fondo principal: #FFFFFF (blanco)
- Texto primario: #1a1a1a (negro casi puro)
- Acento/Botones principales: #FF6B35 o #FF5722 (naranja fuerte)
- Bordes/Divisores: #E0E0E0 (gris claro)
- Hover: Versión 10% más oscura del naranja
